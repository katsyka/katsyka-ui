POST/v1/projects/{id}/deploys

Create a deploy

Builds the given branch and returns the deploy immediately with status building. Poll it or use a webhook to know when it's ready.

Parameters

idpath · requiredstringProject ID or slug.
branchbody · requiredstringGit branch to build.
productionbodybooleanPromote to production when the build succeeds. Default false.
envbodyobjectExtra environment variables for this deploy only.
