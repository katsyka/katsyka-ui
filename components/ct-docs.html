Getting started

Environment variables

Keep secrets out of your code. shipit reads variables from your project settings and injects them at build and run time.

Adding a variable

Run the command from your project folder. The value is encrypted before it leaves your machine.

shipit env add DATABASE_URL --env production

Variables are scoped to an environment. A preview deployment never sees production values unless you copy them explicitly.

Using variables at build time

Build-time variables are baked into the output. Only expose values that are safe to ship to browsers, and prefix them with PUBLIC_ so it's obvious in reviews.

Changing a build-time variable needs a new deploy. Runtime variables take effect on the next request.

Local development

Pull the development values into a local file. It's added to .gitignore automatically.

shipit env pull .env.local

Limits

Each project can have 200 variables of up to 64 KB each. Names are case-sensitive and must start with a letter.
