How it works

  1. One file per component. Markup, a <style> block and an optional <script>. Nothing global leaks: every class is prefixed.
  2. No dependencies. Pure HTML, CSS and JS. Works in React, Vue, Astro or a plain page; port the markup to JSX and keep the CSS.
  3. Motion that behaves. Effects use transforms and opacity, pause offscreen where it matters, and respect prefers-reduced-motion.
  4. Video & frame assets. Video components reference files under media/. Swap in your own loops or frame sequences; the code handles any aspect ratio.
  5. Fonts. Previews use Geist and Instrument Serif from Google Fonts. The downloaded index.html includes the link.
  6. MIT licensed. Free for personal and commercial work, no attribution required. Ship it, change it, sell what you build with it.

Model Context Protocol

Katsyka UI inside your AI

Connect Katsyka UI to Claude, Cursor, VS Code, ChatGPT or any MCP client. Your assistant searches the library and pulls the exact component code into whatever you're building. No key, no install.

https://ui.katsyka.dev/mcp
  1. search_componentsDescribe what you need ("glass pricing table", "date range slider") and get ranked matches.
  2. get_componentReturns HTML, CSS and JS separately, or a complete runnable index.html. Video assets resolve to absolute URLs.
  3. list_componentsThe whole catalogue, or one category. New components show up the moment they're published.
  4. get_design_rulesThe full anti-AI-slop rulebook. The relevant rules also ride along with every component, so your AI follows them while adapting it.

We have anti-AI-slop rules!

Your assistant doesn't just copy code. It gets 60+ rules for the stuff generated UI usually gets wrong.

Colour

Two colours get it right, the third gets it noticed. A calm base plus one bold accent, defined in OKLCH.

Craft

Optical centring, tabular numbers, ~65-character lines, no widows, 44px touch targets, no layout shift.

Motion

Ease-out entrances, 150–250ms menus, popovers that grow from their trigger, 30ms staggers, no bounce on everyday UI.

UX laws

The 20 principles of UX & animation: squash, anticipation, follow-through, arcs, sub-300ms timing, Fitts, Hick, Miller, Doherty, Postel and Jakob.
